# Language support / Dil desteği

Clan & Group System uses XenForo's native phrase/language system. Import `languages/Turkish.xml` or `languages/English.xml` into the corresponding XenForo language (or a child language). The add-on follows the visitor's selected XenForo language.

Clan names, announcements, application answers and other member-created content are not automatically translated.

Yeni kullanıcıya görünen sabit metinler phrase kullanılmadan template/PHP/JS içine eklenmemelidir.
